# Sathwik H Naik — Data Portfolio

A responsive, adaptive light/dark portfolio for a Data Engineer and Data Scientist, built with Next.js App Router, TypeScript, Tailwind CSS, Motion, and accessible progressive enhancement.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

The site is designed for Vercel Git deployments. Set `NEXT_PUBLIC_SITE_URL` to the production origin when using a custom domain; otherwise the configured Vercel origin is used for canonical metadata and the sitemap.
